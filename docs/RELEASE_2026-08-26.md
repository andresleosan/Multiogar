# Release 2026-08-26

## Alcance

- Inicio de sesión general con Google y correo/contraseña.
- Navegación pública hacia el acceso general y protección de rutas administrativas.
- Chat público mediante Route Handlers con identidad temporal HMAC, validación, autorización por conversación y rate limiting transaccional.
- Reglas de Firestore sin permisos administrativos por correo; el personal requiere custom claims.
- Autenticación de Firebase Admin mediante Vercel OIDC y credenciales temporales.

No hay migraciones ni eliminación de documentos en este release.

## Evidencia previa

- `pnpm test`: 21/21.
- `pnpm test:rules`: 4/4 con Firestore Emulator Suite.
- `pnpm lint`: limpio.
- `tsc --noEmit`: limpio.
- `pnpm build`: 31 páginas y 2 Route Handlers.
- `pnpm audit --prod`: una alerta moderada transitiva en `uuid@9.0.1`. Los consumidores detectados (`gaxios` y `teeny-request`) invocan `uuid.v4`; la vulnerabilidad reportada afecta v3/v5/v6 cuando reciben un buffer. No se fuerza una versión mayor porque `gaxios@6.7.1` revirtió previamente ese cambio de dependencia.

Para revertir la aplicación, promover en Vercel el deployment asociado al commit previo. Ninguno de estos rollbacks modifica datos.
